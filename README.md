# PIX Website

Aktueller Portfolio-/Chat-Prototyp für PIX.

## Starten

```bash
npm install
npm run dev
```

Die Hauptseite ist `/`.

Der Canvas-Editor ist `/canvas`.

## Wichtige Dateien

- `src/App.tsx` - Website, Chatlogik, Bilderstreifen, Lightbox
- `src/CanvasEditor.tsx` - Canvas-Editor für den Chat-Baum
- `src/styles.css` - Layout, responsive Verhalten, Light/Dark Mode
- `public/` - alle Bilder, Medien und das PIX Logo, die die Website direkt nutzt
- `source-assets/` - Rohmaterial und Ausgangsassets zum Weiterarbeiten
